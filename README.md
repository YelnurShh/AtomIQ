# AtomIQ

Flutter Android қосымшасы: химиялық теңдеулерді тексеру, AI көмекші және мұғалім әдістемесі.

## Іске қосу

```bash
flutter pub get
flutter run --dart-define-from-file=config/local.json
```

Android Studio-дағы `main.dart` Run Configuration және VS Code конфигурациясына осы аргумент қосылған. Кілт `config/local.json` ішінде, файл Git-ке кірмейді. Таза көшірмеде `config/example.json` үлгісінен өз `config/local.json` файлыңызды жасаңыз.

Groq моделі: `openai/gpt-oss-120b`. Бұрынғы `llama-3.3-70b-versatile` осы аккаунтта model_not_found қайтарды. Жаңа модель нақты API сұрауымен тексерілді. Модельді `GROQ_MODEL` арқылы өзгертуге болады (reasoning_effort параметрін қабылдайтын модель болуы керек).
Кілтті тексеру: `dart run tool/check_groq.dart`. Бұл скрипт кілтті басып шығармайды.

`--dart-define` Git-ке кілттің түсуін болдырмауға көмектеседі, бірақ жиналған APK ішінде кілтті жасыра алмайды. Көпшілікке таратылатын нұсқада Groq сұрауын сервер арқылы өткізу керек.

## Экрандар

- Жарқын градиенттер, модерн минимализм, Montserrat және формулаларға JetBrains Mono.
- Splash, onboarding, оқушы/мұғалім тіркелуі және кіру.
- iPhone стиліндегі үш қадамды onboarding және ресми түсті Google белгісі.
- Оқушыға жеке шолу, сыныпқа кодпен қосылу, тапсырманы орындау, жауап жіберу және мұғалім пікірін/бағасын көру.
- Оқушыға арналған 6 жеңіл жаттығу: теңдеудегі бір бос коэффициентке 1, 2 немесе 3 санын таңдау, бірден түсіндірме алу және прогресті сақтау.
- «Сабақтар» бөлімінде тақырып ретімен берілген 10 химия сабағы бар. Әр сабақта түсіндірме, мысал, 2 тест сұрағы, 3 жұпты сәйкестендіру және сақталатын аяқталу нәтижесі болады. Басты бетте өтілген сабақтар саны көрсетіледі.
- Мұғалімге жеке панель, сынып ашу, шақыру кодын бөлісу, тапсырма жариялау, жауаптарды тексеру және кері байланыс беру.
- Әр сыныпта «Посттар», «Үй тапсырмасы», «Оқушылар» вкладкалары бар. Мұғалім пост пен тапсырма жариялайды; оқушы посттарды оқып, пікір қалдырады және тапсырма жауабын жібереді.
- AI чат, жаңа чат батырмасы, Markdown/LaTeX және тәуелсіз атомдар кестесі.
- Сақталған нәтижелер, санат бойынша сүзгі, жеке нәтиже беті.
- Жеке профиль, аты-жөн мен мектепті өзгерту, рөлді көрсету, шығу.
- Мұғалімге және оқушыға арналған тексеру әдістемесі.

## Firebase

`alhimic-a152b` жобасы қосылған. Google және Email/Password кіру әдістері белсенді. Android debug SHA-1/SHA-256 тіркеліп, OAuth конфигурациясы жаңартылды. Release қолтаңбасы ауысқанда оның SHA сертификаттарын да Firebase-ге қосу қажет.

Google арқылы алғаш кіргенде аты-жөн, мектеп және рөл толтырылады. Бұрынғы аккаунттың рөлі қайта жазылмайды. Профиль `users/{uid}`, нәтижелер `users/{uid}/checks/{id}` ішінде сақталады. Сервер ережелері жарияланған: әр пайдаланушы тек өз деректеріне қол жеткізеді.

Интерактивті жаттығулардың аяқталуы `users/{uid}/practice/{taskId}` ішінде сақталады. Бұл жаңа коллекция үшін жаңартылған `firestore.rules` ережесін Firebase жобасына жариялау керек.

Сабақтың аяқталуы `users/{uid}/lessons/{lessonId}` ішінде сақталады және құрылғыда да белгіленеді. Бұл коллекцияға арналған `firestore.rules` өзгерісі әзірше тек жергілікті файлда: бұлтқа сақтау жұмыс істеуі үшін ережені Firebase жобасына жариялау қажет. Оған дейін қолданба нәтижені құрылғыда көрсетіп, синхрондау қатесін хабарлайды.

Оқу процесі `classes/{classId}` құрылымында сақталады: `members`, `assignments` және әр тапсырма ішіндегі `submissions`. Мұғалім ғана өз сыныбына тапсырма және баға жазады; оқушы тек өзі қосылған сыныптың тапсырмасын оқып, өз жауабын жібереді. Мұғалімнің кері байланысын сол оқушы ғана оқиды.

Сынып посттары `classes/{classId}/posts/{postId}`, пікірлер посттың `comments` ішкі коллекциясында сақталады. Оқушылар тізімі `members` коллекциясынан оқылады. Жаңа пост/пікір және тізімді оқу ережелері жергілікті `firestore.rules` файлына қосылды; нақты Firebase жобасында жұмыс істеуі үшін ережелерді сол жобаға жариялау қажет.

Firebase қатесі кезінде қолданба жасырын демо режиміне ауыспайды. Локалды сынақ режимі тек `--dart-define=ENABLE_LOCAL_DEMO=true` арқылы әдейі қосылады; демо аккаунттар Firebase-ге автоматты көшірілмейді.

## Мұғалім коды

Мұғалім ретінде тіркелу коды: `tech2026`. Код Firebase және локалды режимде бірдей жұмыс істейді. Дұрыс код енгізген кез келген қолданушы мұғалім профилін аша алады. SHA хэш пен `teacherInvites` коллекциясы қолданылмайды.

Бұл қарапайым оқу-жобасына арналған клиенттік тексеру: код APK ішінен табылуы немесе өзгертілген клиентпен айналып өтілуі мүмкін. Профиль мен нәтижелерді әр қолданушы бұрынғыдай тек өзі оқиды және тіркелген рөлін кейін өзгерте алмайды.

## Дизайн қағидалары

[Emil Kowalski skills](https://github.com/emilkowalski/skills) жинағындағы `emil-design-eng` және `animate` қағидалары Flutter виджеттеріне бейімделді: ақ беттер, айқын иерархия, оқылатын контраст, 140 мс батырма кері байланысы, 160 мс навигация акценті. Жиі қолданылатын экрандарда сәндік цикл анимациясы жоқ. Жүйенің reduced-motion параметрі қозғалысты сөндіреді; белсенді емес беттердің ticker-лері тоқтатылады. React/Swift тәуелділіктері қосылған жоқ.

Атомдық тексергіш бейтарап молекулалардың қарапайым теңдеулеріне арналған; заряд теңгерімін, реакция жүру шартын және ең кіші коэффициенттерді толық дәлелдемейді. Бұл деректерді мұғалім әдістемесімен тексеріңіз.
